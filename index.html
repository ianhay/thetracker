    AISStream has a known "silent socket" issue Public reports (aisstream/aisstream issue #15) describe exactly this: the connection opens, the subscription is accepted, and zero frames ever arrive — reproduced even with an empty API key, so it is not specific to any one account. If your log shows the same pattern, the key is very likely fine and the fault is upstream. Keep the socket enabled — it may recover without any change here — and use VesselAPI spot check or demo vessels below in the meantime.

    A REST alternative for when AISStream is silent. Its free tier is capped at 150 calls per month, so this is deliberately manual only — there is no automatic polling, and each button press spends one call. Sign up at dashboard.vesselapi.com for a free key.
